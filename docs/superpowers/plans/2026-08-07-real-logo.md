# Real Logo Rollout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the interim painted-sign logo and placeholder "TY" favicon with assets derived from the client's real logo artwork (rosette mark in nav/footer, traced-rosette favicon, full-badge og:image).

**Architecture:** Three asset derivations from the PDF's embedded 1000×1000 raster, then three component edits: Nav and Footer render mark + name together instead of either/or; BaseHead's og:image becomes a static file instead of a Sanity derivation. Sanity's `settings.logo` is updated via `make set-logo` at the end (content, not code).

**Tech Stack:** Astro 7, Sanity image pipeline (`urlFor`), ImageMagick + poppler (`pdfimages`) + potrace for asset prep.

**Spec:** `docs/superpowers/specs/2026-08-07-real-logo-design.md`

## Global Constraints

- No test framework: verification is `make check` (types, lint, build) + grep assertions on built output. Component CSS lands in external `dist/_astro/*.css`, page markup/meta in `dist/index.html` — grep the right surface.
- Never run the dev server (blocked by hook); browser verification happens in Benny's running server.
- Logo img tags use `alt=""` (site name is adjacent real text). The always-rendered name spans keep the existing classes (`.brand-mark` nav, `.footer-brand` footer).
- Rosette green `#199131`. Baked-background pale field `#f1f5f7`.
- Asset workspace: `/private/tmp/claude-501/-Users-benny-dev-treatyourselfstudios/44518fca-70cb-4138-b749-037b8cfb8678/scratchpad` (already contains the extraction pipeline outputs from brainstorming: `logo-extracted.png`, `logo-transparent.png`, `rosette-crop2.png`, `rosette-traced-bold.svg`).

- [ ] **Step 1: Nav brand row**

In the Nav `<style>`, extend the `.brand` rule (or add one if only `.brand-mark` is styled) so mark and name align: `display: flex; align-items: center; gap: var(--space-2);`. Do not restyle `.brand-mark`.

- [ ] **Step 2: Footer brand row**

Replace:

```astro
        { logoUrl
          ? <img src={ logoUrl } alt={ settings.siteTitle } height="48" />
          : <p class="footer-brand">{ settings.siteTitle }</p> }
```

with:

Add to the Footer `<style>`: `.footer-brand-row { display: flex; align-items: center; gap: var(--space-2); }`. Check the existing `.footer-brand` rule for margins that break vertical centering (`margin: 0` it inside the row if needed).

- [ ] **Step 3: BaseHead static og:image**

Replace line 19:

```astro
const ogImageUrl = settings.logo ? urlFor( settings.logo ).width( 1200 ).height( 630 ).fit( "crop" ).url() : undefined;
```

with:

```astro

```

The `{ ogImageUrl && … }` guard on the og:image meta becomes always-true — simplify it to an unconditional `<meta property="og:image" content={ ogImageUrl } />`. JSON-LD `image: ogImageUrl` (line 28) needs no edit and now always carries a value. `urlFor` remains used for nothing in BaseHead — remove the now-unused `import { urlFor }` (eslint will flag it otherwise).

Note: until `make set-logo` runs (Task 3), `settings.logo` in Sanity is still the painted-sign image, so the built nav shows that image next to the name — expected interim state.
